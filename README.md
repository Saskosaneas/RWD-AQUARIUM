# RWD-AQUARIUM

A responsive web‑design aquarium demo that showcases interactive fish animations using JavaScript and CSS.

## Features
- Responsive layout for mobile & desktop.
- Interactive fish animations triggered by user actions.
- Audio effects for fish interactions.
- Simple, lightweight implementation without external frameworks (except jQuery).

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/RWD-AQUARIUM.git
   ```
2. Open `index.html` in your browser.

No build steps are required; all assets are static.

## Project Structure
- `index.html` – Main page.
- `css/styles.css` – Styling.
- `js/script.js` – Custom JavaScript logic.
- `js/jquery-3.3.1.js` – jQuery library (bundled).
- `audio/` – Sound files used in the demo.
